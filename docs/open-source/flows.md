# 关键流程

## 当前页面编辑

1. 用户点击扩展并主动启动 Dock。
2. 内容脚本识别当前页面类型和可编辑对象。
3. 用户选择对象并修改文字、外观、间距或布局。
4. 扩展写回当前页面副本，记录 before/after，并提供撤销和重做。
5. 用户可进入完整工作台继续调整或导出静态结果。

失败时应拒绝不稳定目标，并向用户说明原因，不生成看似成功但无法复现的修改记录。

## 本地 HTML 或网页副本

1. 用户从完整工作台选择本地 HTML 或主动输入 HTTP(S) 地址。
2. 扩展按浏览器权限规则请求必要的站点访问权。
3. 页面以当前渲染结果加载到工作台画布。
4. 修改只作用于当前会话或导出的静态副本，不写回原站点源码。

## 静态导出

- HTML 导出：读取可访问的样式、图片、图标和字体资源，生成静态 HTML；失败资源必须被明确列出。
- 整页 PNG：临时隐藏 Dock、选框、测量和参考线，分段截图并拼接，完成后恢复页面滚动位置。

## AI 交接

扩展只根据稳定对象定位、before/after 状态、页面约束和验收条件生成提示词，并写入剪贴板。扩展不执行外部 Agent、不上传页面内容。

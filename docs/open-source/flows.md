# 关键流程

这些流程只记录权限、数据完整性或副作用实际经过的路径，不是功能 PRD。点睛没有服务器、job、邮件、provider 或 webhook；流程中的“服务端”均不存在，浏览器 service worker 是本地扩展边界。

## 1. 当前页面 Dock 编辑

**Actor/前置条件：** 用户主动点击扩展；当前标签页不是浏览器内部页/商店页，且浏览器允许当前 tab 的 `activeTab`/`scripting` 访问。

**成功结果：** 用户在当前页面副本完成可撤销修改，修改记录可继续交给完整工作台或导出；原站点源码不变。

1. action 触发 service worker，按 `entry-policy.ts` 判断页面类型；内部页或禁止页面直接拒绝并返回原因。
2. service worker 用 `tabs.sendMessage` 探测已有内容脚本；没有脚本时才在当前 tab 通过 `scripting.executeScript` 注入。此处的授权是浏览器的当前 tab 权限，不是账号 claim。
3. 内容脚本扫描可编辑对象并依据稳定定位、Canvas/iframe/媒体等能力分类；不稳定目标拒绝写入。
4. 用户修改文字、外观、间距或布局；协议校验 before/after，内容脚本写当前页面副本并把记录放入当前会话。
5. 撤销/重做/取消只改变当前会话中的页面副本和历史。

**拒绝与副作用：** 浏览器 API 拒绝、页面不支持或定位不稳定时不生成成功记录；成功路径只改变当前页面/会话，不写网站源码、不上传数据。

## 2. 本地 HTML 工作台

**Actor/前置条件：** 用户从完整工作台选择本地 HTML，并在浏览器扩展设置中允许 file URL（如浏览器要求）。

**成功结果：** 处理后的本地 HTML 在工作台画布中可编辑，并可在用户选择保存位置后导出新的静态副本。

1. 工作台读取用户选择的文件，`local-html-document.ts` 解析并禁用本地脚本、内联事件、自动跳转和不适合静态预览的行为。
2. 处理后的 HTML 通过扩展内本地预览加载到画布；不请求服务器，也不通过 `storage.session` 传输整份 HTML。
3. 用户修改对象，状态只保留在当前工作台会话；页面内容或文件只有在用户主动导出时才生成新副本。

**拒绝与副作用：** 读取失败、未授予 file URL 或 HTML 不可解析时显示原因并停止；不会覆盖原文件，不会新增后台标签页。

## 3. HTTP(S) 网页副本

**Actor/前置条件：** 用户在工作台主动输入完整 `http://` 或 `https://` 地址。

**成功结果：** 用户授权的目标页面被打开或复用为当前会话，工作台可编辑其渲染副本并导出，不写回原网站。

1. 工作台校验 URL 方案，若该站点 host permission 不存在，调用 `chrome.permissions.request({ origins })`。用户拒绝时不创建编辑会话。
2. service worker 复用同 URL 标签页或创建 source tab，确认页面可注入后创建/复用 workspace tab，并把 `sessionId` 放入 `chrome.storage.session`。
3. 内容脚本在 source tab 中工作台副本上执行修改；每条 workspace 消息都要求已存在的 session 和已知 command。
4. 用户导出的是当前静态渲染副本或整页 PNG；原 HTTP(S) 站点源码、账号状态和服务器数据不被写回。

**拒绝与副作用：** 无权限、浏览器内部 URL、注入失败或页面不支持时拒绝并清理新建 tab；成功路径可能打开/复用标签页并写入浏览器 session storage，但不向项目服务器发请求。

## 4. 完整工作台编辑与导出

**Actor/前置条件：** 已有有效 session，工作台能读取 source tab 状态。

**成功结果：** 对象树、画布、检查器和历史保持同一有效对象身份，用户可以导出当前静态 HTML 或整页 PNG。

1. 工作台向 service worker 发送带 `sessionId` 的 `workspace/request`；缺失/过期 session 由 service worker 拒绝。
2. source tab 返回页面快照和 selectable targets；对象树/画布只使用稳定 ID，修改前后快照进入历史。
3. 单对象属性、对象树结构拖放和多对象布局通过同一修改协议提交；撤销/重做恢复快照及真实 DOM 位置。
4. HTML 导出在用户点击后读取可访问样式/图像/图标/字体资源；PNG 导出临时隐藏 Dock/选框/测量/参考线，调用 `tabs.captureVisibleTab` 分段截图，拼接后恢复滚动位置。

**拒绝与副作用：** session 无效、资源读取失败或截图 API 失败时显示失败项，不生成伪成功文件；导出可能触发用户保存窗口或下载流程，但不覆盖源文件，除非用户在系统窗口明确选择覆盖。

## 5. AI 交接

**Actor/前置条件：** 用户在 Dock 或工作台主动点击“复制 AI 提示词”，且当前会话存在有效修改记录。

**成功结果：** 修改结果以包含定位、最终状态和验收条件的提示词写入用户剪贴板，等待用户交给外部工具。

1. 本地从稳定对象定位、before/after、结构动作、约束和验收条件生成提示词包。
2. 用户点击剪贴板写入；浏览器拒绝剪贴板时显示失败，不伪造“已复制”。
3. 用户自行把文本交给外部开发工具或 AI Agent。

**边界与副作用：** 扩展不执行 Agent、不调用 LLM、不上传页面内容；剪贴板写入是唯一外部可见副作用。没有记录时只提示“当前没有可同步的有效修改”。

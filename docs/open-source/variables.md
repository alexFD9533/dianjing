# 配置、变量与数据

## 当前配置

当前正式扩展没有服务端环境变量、账号密钥、数据库连接或项目自有 API。构建配置位于根 package.json、各 workspace package 和 apps/dock-extension/vite.config.ts。

| 数据               | 存储/去向                      | 是否上传 |
| ------------------ | ------------------------------ | -------- |
| 当前会话和修改记录 | 浏览器扩展会话存储             | 否       |
| 工作台视口设置     | 浏览器本地存储                 | 否       |
| AI 交接提示词      | 用户系统剪贴板                 | 否       |
| HTML 导出资源      | 当前浏览器内存和用户选择的文件 | 否       |
| 整页 PNG 分段      | 当前浏览器内存和用户下载流程   | 否       |

## 发布前检查

- 不提交 .env、私钥、Token、真实业务数据或未脱敏截图；
- 不把浏览器权限扩展成默认全站权限；
- 不在构建产物中嵌入账号、服务器地址或调试日志；
- 新增外部网络请求时，必须同时更新本文件、权限说明和安全审查。

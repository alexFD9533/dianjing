# 权限矩阵

| 权限                    | 使用位置             | 用途                         | 公开承诺                   |
| ----------------------- | -------------------- | ---------------------------- | -------------------------- |
| activeTab               | MV3 manifest         | 用户主动点击后访问当前标签页 | 不作为后台全站扫描权限     |
| scripting               | 内容脚本注入         | 在用户启动编辑时运行 Dock    | 只服务当前编辑会话         |
| storage                 | 工作台和协议包       | 保存本地设置或会话数据       | 不上传到项目服务器         |
| permissions             | background/workspace | 请求用户主动选择的站点权限   | 授权前不应访问普通网页     |
| http://_/_、https://_/_ | manifest 可选权限    | 用户主动进入普通网页副本模式 | 不等于默认后台读取所有网页 |

## 拒绝情况

浏览器内部页面、扩展商店、未获授权的本地文件和定位不稳定的对象应保持不可编辑，并给出可理解的原因。权限扩展、源码回写、云端同步或 Agent 工具调用必须先更新本文件和对应测试。

# 架构与信任边界

## 产品概览

点睛是一个 Manifest V3 浏览器扩展。用户在当前网页或本地 HTML 上选择稳定 DOM 对象，扩展在页面内执行可撤销的文字、样式、间距和布局调整；完整工作台提供多对象操作、历史和静态导出。

## 主要组件

| 组件                               | 责任                                         |
| ---------------------------------- | -------------------------------------------- |
| apps/dock-extension/src/content    | 页面内 Dock、对象识别、修改和导出            |
| apps/dock-extension/src/background | MV3 service worker、会话消息、授权和截图拼接 |
| apps/dock-extension/src/workspace  | 完整工作台 UI、画布、对象树和布局操作        |
| packages/contracts                 | 修改协议和输入校验                           |
| packages/selector-engine           | 稳定 DOM 目标定位                            |

## 数据流

点睛没有服务器端账号、数据库或上传 API。页面修改通过扩展消息和浏览器本地会话传递；工作台视口设置使用本地存储；提示词写入系统剪贴板；离线 HTML 导出会在本地读取可访问资源并生成静态副本；整页 PNG 通过浏览器截图能力采集并在本地拼接。

## 信任边界

1. 用户页面与扩展内容脚本之间：页面 DOM 不可信，目标定位和修改协议必须经过校验。
2. 内容脚本与 service worker 之间：消息包含页面会话数据，必须限制为已知命令和当前会话。
3. 扩展与目标网站资源之间：资源读取只为用户主动导出服务，不应成为后台上传通道。
4. 本地导出结果与用户文件系统之间：由用户选择保存位置，扩展不直接覆盖任意源文件。

## 已知风险与假设

- 普通网页和动态组件可能在编辑后改变 DOM，稳定定位失败时应拒绝写入；
- 跨域 iframe、Shadow DOM、复杂 Canvas 和不可读取资源存在天然边界；
- 浏览器权限提示和页面副本语义必须在 UI 中清楚表达；
- 任何未来的云端同步、外部 Agent 或源码回写都需要单独的安全与权限设计。

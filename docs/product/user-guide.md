# 点睛试用指南

这份指南写给第一次收到点睛链接的试用者。你不需要先理解代码仓库，只需要知道点睛能帮助你在 AI 生成网页、HTML 原型或 HTML 演示上完成最后一轮文字、样式和布局调整。Dock 适合当前页面快速修改，完整工作台适合像使用 Axure 一样精修已有原型；点睛不从空白构建内容，也不生成 `.pptx` 文件。

## 当前能不能直接安装

目前源代码已经公开，但首个 Alpha Release 尚未发布，Chrome 扩展商店也还没有上架点睛。

- **普通试用者**：请等待 GitHub Release，或向项目维护者索取经过验证的扩展包；
- **开发者**：可以按照根目录 [README](../../README.md#开发者从源码构建) 从源码构建；
- **不要**从陌生网盘或非本项目 Release 页面安装来源不明的扩展包。

项目发布首个 Release 后，可从 [GitHub Releases](https://github.com/alexFD9533/dianjing/releases) 下载。

## 拿到安装包后的安装方法

1. 从项目维护者或 Releases 页面取得名称类似 `dianjing-v0.1.0-alpha.zip` 的文件；
2. 把 ZIP 完整解压到一个固定文件夹，不要直接从压缩包内打开；
3. 在 Chrome 地址栏输入 `chrome://extensions`；
4. 打开右上角“开发者模式”；
5. 点击“加载已解压的扩展”，选择刚才解压后、包含 `manifest.json` 的文件夹；
6. 在浏览器扩展菜单里找到“点睛”，建议将它固定到工具栏。

更新 Alpha 版本时，请重新下载和解压，再到扩展管理页移除旧版或重新加载新版。不要把两个不同版本同时加载，以免无法判断当前使用的是哪一版。

## 第一次使用：5 分钟体验

### 路径一：编辑本地 HTML

1. 点击浏览器工具栏里的“点睛”；
2. 进入完整工作台，选择“打开 HTML”；
3. 选择一个不含账号、客户数据或内部地址的测试 HTML；
4. 在画布或左侧页面结构中选中标题；
5. 修改一段文字，再调整颜色、字号或间距；
6. 尝试撤销和重做；
7. 导出离线 HTML 或整页 PNG，检查结果是否符合预期。

### 路径二：编辑普通网页副本

1. 打开希望试用的普通网页；
2. 主动点击“点睛”，按浏览器提示授予当前站点访问权限；
3. 选中稳定的文字或页面模块进行调整；
4. 修改只作用于当前会话或网页副本，不会写回原网站服务器；
5. 如果页面包含登录信息、真实客户数据或其他敏感内容，Alpha 阶段建议改用脱敏测试页面。

## 你应该重点体验什么

- 是否能在看到问题时直接选中并修改，而不是重新描述给 AI；
- Dock 能否满足改文字、颜色、字号和间距等快速调整；
- 完整工作台的对象树、画布和布局面板能否帮助你精修已有 HTML 原型或演示版式；
- 文字、外观、间距和布局操作是否符合你的日常修改习惯；
- 撤销、重做和修改记录能否让你放心尝试；
- 离线 HTML、整页 PNG 和 AI 交接提示词是否能进入你的交付流程。

点睛不是源码生成器，也不会直接修改 React、TSX、Vue 等源码。跨域 iframe、Shadow DOM、复杂 Canvas 和部分动态组件可能只能整体选择或暂不支持。

## 如何反馈

请在 [GitHub Issues](https://github.com/alexFD9533/dianjing/issues) 提交反馈。不会写代码也完全可以，只要尽量说明：

1. 你当时想完成什么；
2. 使用的是本地 HTML、localhost，还是普通网页副本；
3. 你做了哪些操作；
4. 实际发生了什么，你原本期待什么；
5. Chrome/Chromium 版本和点睛版本；
6. 可以公开的脱敏截图或最小示例 HTML。

请不要上传账号、Token、客户数据、内部网址、私人页面内容或其他敏感信息。安全问题请按照根目录 [SECURITY.md](../../SECURITY.md) 私下报告，不要先公开利用细节。

## 常见问题

### 点睛会直接改掉原网站吗？

不会。普通网页修改作用于当前会话或网页副本；本地 HTML 在工作台内编辑后导出新的静态结果。是否覆盖本地文件，由你在系统保存窗口中决定。

### 不会写代码能用吗？

页面选择和视觉调整不要求写代码；但 Alpha 阶段仍需要手动加载扩展。等 GitHub Release 发布后，安装过程会比从源码构建简单很多。

### 它能编辑所有网站吗？

不能。点睛优先支持本地 HTML、localhost 和用户主动授权的普通网页副本。浏览器内部页面、扩展商店、跨域 iframe、复杂 Canvas、Shadow DOM 和定位不稳定的对象会受到限制。

### “AI 交接”会自动调用 AI 吗？

不会。点睛只整理并复制交接提示词，由你决定是否发送给自己的开发工具或 AI Agent。

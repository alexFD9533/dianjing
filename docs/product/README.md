# 当前产品文档

这里是点睛当前公开产品定义的入口。它描述正在开发的正式 MV3 扩展，不是历史原型或旧版插件的迁移计划。

- [产品定义](product-definition.md)：用户、问题、正式能力和明确不承诺的边界。
- [品牌规则](brand.md)：点睛的名称、主张和对外用语。
- [Alpha 发布范围](alpha-release.md)：首个公开 Alpha 的进入条件、验收证据和未完成项。

产品文档必须与 `apps/dock-extension` 的实际行为保持一致；工程安全、权限和测试细节以 [开源工程说明](../open-source/README.md) 为准。产品状态仍需区分“已规划、已实现、已验证、已验收、已发布”。

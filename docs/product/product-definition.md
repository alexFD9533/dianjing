# 点睛产品定义

## 产品定位

点睛是“AI 创作的最后一笔”：面向产品经理、设计师和前端协作者的浏览器端最后一公里编辑器。用户在真实渲染页面上选择稳定 DOM 对象，完成文字、外观、间距和布局微调，再把无法直接写回源码的结果整理成可执行的 AI 交接提示词。

点睛当前的正式产品不是页面重构原型，也不是源码生成器。`apps/dock-extension` 是唯一正式运行入口。

## 正式能力

| 层级       | 能力                                                     | 交付语义                                                  |
| ---------- | -------------------------------------------------------- | --------------------------------------------------------- |
| Dock       | 当前页面选中、文字/外观/间距调整、撤销重做和修改记录     | 写入当前页面会话或网页副本，不写回站点源码                |
| 完整工作台 | 页面结构树、真实页面画布、单/多对象布局、历史和本地 HTML | 与 Dock 共用会话，支持结构调整和静态交付                  |
| 导出       | 离线 HTML 和整页 PNG                                     | 导出当前渲染结果；用户选择保存位置                        |
| AI 交接    | 按稳定对象、before/after、约束和验收条件生成提示词并复制 | 用户主动复制给自己的开发工具或 AI Agent；扩展不执行 Agent |

## 目标用户与首个场景

首个场景是已经有一个 AI 生成或本地 HTML 页面、需要快速调整视觉细节并把结果交回开发链路的人。重点价值是“看到真实页面就能改，并且改动可追踪、可撤销、可交接”。

## 不承诺的能力

- 不直接修改 React、TSX、Vue 等源码，也不提供服务器端源码回写。
- 不保证跨域 iframe、Shadow DOM、复杂 Canvas、动态组件或无法读取资源的完整编辑。
- 不上传页面内容，不提供账号、云端数据库、云端同步或内嵌 Agent。
- 普通 HTTP(S) 页面需要用户主动输入地址并授予对应站点权限；网页副本修改不等于修改原站点。

## 成功判断

每项优化都使用统一状态：`已规划 → 已实现 → 已验证 → 已验收 → 已发布`。其中“已验证”要求代码/测试证据，“已验收”要求真实浏览器或用户确认，“已发布”要求版本 tag、GitHub Release 和 zip 产物。

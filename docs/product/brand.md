# 点睛品牌规则

## 核心定义

- 产品名：点睛（Dianjing）。
- 品牌主张：AI 创作的最后一笔。
- 产品品类：已有网页与 HTML 的最后一公里编辑器。
- 核心表达：应手编辑——让非开发创作者像使用 Axure、PPT 一样，直接调整真实 HTML 的最终呈现。
- 核心结构：Dock 负责当前页面的快速修改，完整工作台负责像 Axure 一样精修已有原型。
- 核心边界：不是画龙，是点睛；不从空白生成内容，不把“HTML 做 PPT”表述成生成 `.pptx`。

## 用词边界

- 对外统一使用“点睛”，正式入口统一写 `apps/dock-extension`。
- “Dock”指当前页面中的轻量入口；“完整工作台”指同一 MV3 扩展中的页面结构、画布和交付界面。
- “AI 交接”指用户主动复制的提示词，不写成“点睛内置 Agent”“点睛替用户调用 AI”或“自动修改源码”。
- “网页副本”指当前渲染结果或当前会话，不写成“修改原网站”。
- “像 Axure”只描述已有 HTML 的对象选择、结构查看、属性和布局调整，不承诺从零绘制、组件库或交互逻辑编排。
- “HTML 做 PPT”指用 HTML 制作演示、汇报和数据故事，交付离线 HTML 或整页 PNG，不写成 PowerPoint 文件生成器。
- “成章”“页面重构工作台”仅可作为历史品牌/历史文档说明，不得作为当前对外品牌或产品入口。

## 视觉与文案原则

使用克制、清楚、可验证的语言说明能力。涉及权限、导出和 AI 交接时，优先写出用户动作、实际副作用和限制，不用“全自动”“任意网页”“无损源码”等无法证明的承诺。

# 点睛 Dock 扩展

> **AI 创作的最后一笔。**

这是点睛的真实浏览器扩展产品，面向网页设计、AI 原型和 HTML 演示的最后一轮精修。Dock 是当前网页中的轻量入口，完整工作台与 Dock 一起打包在同一个 MV3 扩展中，共用原标签页、选中对象和修改历史。Dock 负责快速修改，完整工作台提供类似 Axure 的已有原型编辑感受；点睛不是从空白构建内容的工具。

## 当前范围

- 空白页点击扩展会直接打开不依赖原页面的完整工作台，可选择本地 HTML；`file://` 未授权时显示授权引导并提供前往扩展设置的动作；
- 本地 HTML、localhost 和 127.0.0.1 保持直接编辑；普通 `http/https` 页面可在用户主动点击后进入“网页副本模式”，修改只作用于当前标签页且不会写回原网站；浏览器内部页和扩展商店仍受浏览器保护；
- 点击页面元素后直接修改单行或多行文字、文字色、文字高亮、元素背景、边框、圆角、字号、字体和文字格式；字号滑块会在拖动时实时显示当前 `px`，悬停/聚焦时保留同一数值提示；
- 字体下拉提供页面默认、系统默认、微软雅黑、苹方、黑体、宋体、Arial、Helvetica Neue、Georgia、Times New Roman、Consolas 和 Courier New 等常用字体栈，不假装枚举所有已安装字体；
- 多行文字会同步到页面：普通 HTML 文本元素自动使用 `white-space: pre-wrap` 保留换行，撤销、重做和离线 HTML 导出也保持一致；
- 使用“文字 / 外观 / 间距”三个属性页签：文字颜色与文字高亮归入“文字”，元素背景与边框归入“外观”；间距页支持文字位置以及上下左右内边距、外边距；
- 支持复制、上移、下移、暂时隐藏和从页面结构中移除当前部件；隐藏只影响画布展示、不改变页面布局，并在对象树中保留为“已隐藏”状态，移除前需要确认且仍可撤销；
- 支持 `↑` 上级、`↓` 下级、`←` / `→` 同级选择；
- Dock 工具栏默认位于底部居中，可通过左侧拖动把手在当前视口内调整位置，也支持聚焦后使用方向键微调；
- 支持撤销、重做、修改记录和取消具体记录；
- 工作台“导出离线 HTML”会内嵌页面样式、图片、图标和字体等视觉资源，将当前 Canvas 画面定格为图片，并移除联网脚本与静态交付无关的媒体；导出面板会按扫描、画布定格、样式内嵌、资源读取和文件生成显示实时进度，单项资源读取有超时和并发保护，结束后显示文件体积。原网页样式中已经返回 404 的图片会以透明占位保留版面并列为提示；其他资源无法完整采集时会保留当前画布、明确提示失败并允许重试，不生成不完整文件。HTML 导出旁提供“整页 PNG”：截图前临时隐藏 Dock、选择框、测量与参考线，逐段滚动并拼接完整页面，成功或失败都会恢复原滚动位置；不申请 `downloads` 或 `<all_urls>` 权限；
- 支持从完整工作台选择并真实打开单文件 HTML；文件直接替换当前工作台画布、对象树和修改记录，不新增标签页或重复打开 Dock，也不经过运行时消息和 `storage.session` 传输整份 HTML；本地脚本、内联事件、页面 CSP 和自动跳转会禁用，修改后可导出静态 HTML 副本；
- 完整工作台可直接输入 HTTP(S) 链接进入编辑：首次访问某站点时仅请求该站点的可选访问授权，后台打开目标页并复用当前工作台；普通网页按网页副本模式处理，不需要先在目标页唤起 Dock；
- 点击 Dock 最右侧的“进入完整工作台”按钮可打开同一扩展内的完整工作台；工作台采用“页面结构树 + 真实页面画布 + 属性/布局检查器”，支持 Ctrl/⌘ 多选、对象树展开收起、参考线开关、缩放、适应画布和平移；鼠标位于画布时，Ctrl/⌘ + 滚轮直接缩放画布而不缩放浏览器；
- 完整工作台不再复制 Dock 的“文字 / 外观 / 间距”页签。单对象属性按内容、字体与文字、填充与边框、尺寸、间距连续展示；多对象布局提供六向对齐、水平/垂直分布、统一间距、统一尺寸和同容器组合；
- 选中稳定对象后，拖动亮色选框的边线可在画布中自由移动，八个圆点用于调整尺寸；单选对象的“布局”栏还可直接输入横向、纵向偏移，首次输入会启用相对定位并保持在页面文档流内。拖动对象本身或对象树仍用于结构调整，放置提示区分对象前、对象后和容器内部；对象树支持将已多选的多个对象按原顺序一起拖入目标容器，真实改变父容器并同步画布展示。两类修改都会立即写入同一份记录，并支持撤销、重做和取消单项；
- 工作台中的单对象属性会写入原标签页的 Dock 编辑引擎并进入顶部变更记录；文字和数字输入在失焦后再应用，避免打字过程中打断编辑；滑块与颜色选择保持实时预览，并合并连续操作记录；
- 选中对象后按真实 DOM 能力判断显示 `可直接编辑`、`可调整外观`、`仅支持整体调整` 或 `定位不稳定 · 暂不修改`；Canvas、iframe、媒体和复杂 SVG 可选中但不伪造内部文字编辑；
- 不执行 AI，不直接写回原文件，不修改 React/TSX/Vue 源码。

## 构建与加载

```powershell
pnpm.cmd --filter @workbench/dock-extension build
pnpm.cmd test:dock:e2e
pnpm.cmd test:dock:workspace
```

在 Chromium 的扩展管理页开启开发者模式，加载 `apps/dock-extension/dist`。旧的 `apps/extension` 不属于本扩展的运行入口，本轮不会覆盖或改写它。

## 当前实现边界

这是正式产品的第一条真实页面闭环，不是任意网站的源码复制器。网页副本模式以当前渲染 DOM 为准：离线 HTML 会冻结导出当时的文字、数据、样式和 Canvas 画面，但不保留登录态、接口数据刷新、路由或动态脚本行为。跨域 iframe、被跨域污染而无法读取的 Canvas、Shadow DOM 及无法读取的资源会明确报错，不生成“缺资源”的离线文件。目标没有稳定 `data-edit-id`、唯一 id、唯一 class 或唯一结构路径时，Dock 会拒绝写入并提示定位风险；iframe、复杂 Canvas、Shadow DOM 和动态组件适配放到后续阶段。

当前 Dock 的保存语义是“导出当前页面快照”：点击后打开系统保存窗口，由用户选择保存位置和文件名；不直接写回原文件。用户可以在保存窗口中选择新文件名或确认覆盖原 HTML；React、TSX、Vue 页面只导出当前静态渲染结果。

对象能力是运行时判断：先检查稳定定位，再识别 Canvas、iframe、媒体、SVG 等不可拆分对象，最后根据是否包含内部子元素决定文字页是否可用。切换对象会重新计算状态；普通 HTML 文字可直接编辑，复杂对象只提供整体外观和间距操作，没有稳定定位的对象不产生修改记录。

“复制 AI 提示词”只生成交付文案并写入系统剪贴板，不下载 Markdown 或其他提示词文档；完整工作台同样使用这份真实修改记录生成源码交接提示词。
